# Credit Card Default Prediction

This project predicts whether a customer will default on credit card payment using machine learning.

## Models Used
- Logistic Regression
- Random Forest
- XGBoost (Final Model)

## Evaluation Metrics
- Precision
- Recall
- F1 Score
- ROC-AUC

## Key Insight
Payment behavior (PAY variables) is the most important factor in predicting default risk.
